# Library Management System

## Description
A simple library management system built with Java.

## Features
- Add books and e-books
- Register members
- Borrow and return items
- Search by title or author

## Technologies
- Java 17+
- OOP
- Custom Exceptions

## How to Run
1. Clone the repository
2. Open in IntelliJ IDEA
3. Run Main.java
